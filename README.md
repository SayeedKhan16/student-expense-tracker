# Student Expense Tracker

## About
A Python application that helps students
record and manage their daily expenses.

## Features
- Add daily expenses
- Categorize expenses
- View all recorded expenses
- Calculate total spending
- Calculate monthly spending
- View category-wise summaries
- Delete expenses
- Store records using CSV files

## Technologies Used
- Python
- CSV file handling
- datetime module

## How to Run
1. Install Python 3.
2. Download main.py.
3. Open a terminal in the project folder.
4. Run:

   python main.py
